# Recipe Sharing App

A simple recipe sharing application built with React and Zustand for state management.

## Features

- View a list of recipes
- Add new recipes with title, description, ingredients, and instructions
- Delete recipes
- Form validation
- Responsive design

## Technologies Used

- React 18
- Zustand for state management
- Vite for build tooling
- CSS for styling
